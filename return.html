Return a Book

Finished reading a borrowed textbook? Return it so another student can use it.

How it works:
1. Select a currently unavailable book.
2. Click Return Book.
3. The C backend updates its status to Available.
4. The book becomes visible as available in Explore Books.

Note: This prototype does not independently verify the identity of the borrower.
